# E-commerce Copywriting Tool

A simple Streamlit web application that leverages the Google Gemini API to generate high-quality marketing copy for e-commerce businesses. This tool helps small business owners and marketers overcome writer's block and create engaging social media content in seconds.

## 🚀 The Problem

Small e-commerce businesses and freelance marketers often struggle to consistently create on-brand, high-quality Instagram copy. This essential marketing task is time-consuming and creatively draining, leading to generic posts that fail to drive engagement and sales. This project aims to solve that problem by providing a simple, fast, and effective AI-powered copywriting assistant.

## ✨ Features

*   **Intuitive UI:** A clean and simple web interface built with Streamlit.
*   **Detailed Product Input:** A structured form to capture essential product details, brand tone, and target audience.
*   **AI-Powered Generation:** Uses the Google Gemini API (specifically `gemini-1.5-flash` by default) to generate creative and relevant marketing copy.
*   **Structured Output:** Generates three unique Instagram captions, a block of relevant hashtags, and two distinct calls-to-action (CTAs).
*   **User-Friendly Experience:** Displays a loading spinner during generation and provides clear error messages for common issues (e.g., missing API key, generation failures).
*   **Easy Export:**
    *   **Copy to Clipboard:** Buttons to quickly copy individual captions, the hashtag block, or the CTA list.
    *   **Download as TXT:** A download button to save all generated results to a single text file.
*   **Tested & Reliable:** Includes a suite of unit and integration tests written with `pytest` to ensure the core logic is working correctly.

## 🛠️ Tech Stack & Dependencies

*   **Backend:** Python
*   **Frontend:** Streamlit
*   **AI Model:** Google Gemini API
*   **Testing:** Pytest, Pytest-Mock
*   **Key Python Libraries:** `requests`, `python-dotenv`, `streamlit-extras`, `st-copy`

## ⚙️ Setup Instructions (Windows)

Follow these steps to set up and run the project locally on a Windows machine.

### 1. Create a Virtual Environment

First, open a terminal or command prompt, navigate to the project's root directory, and create a Python virtual environment.

```bash
python -m venv .venv
```

### 2. Activate the Virtual Environment

Activate the newly created environment.

```bash
.venv\Scripts\activate
```

### 3. Install Dependencies

Install all the required Python packages using the `requirements.txt` file.

```bash
pip install -r requirements.txt
```

## 🔑 Configuration

### Environment Variables

The application requires a Google Gemini API key to function.

1.  **Create a `.env` file:** In the root of the project, create a new file named `.env`.
2.  **Set the API Key:** Add your Gemini API key to the `.env` file like this. **Do not wrap the key in quotes.**

    ```
    GEMINI_API_KEY=YOUR_API_KEY_HERE
    ```

3.  **Optional: Override the Model:** The application uses `gemini-1.5-flash` by default. You can override this by setting the `GEMINI_MODEL` environment variable in the same `.env` file.

    ```
    # Example to use a different model
    GEMINI_MODEL=gemini-pro
    ```

## ▶️ How to Run the Application

With your virtual environment activated and your `.env` file configured, start the Streamlit application with the following command:

```bash
streamlit run app.py
```

Your web browser should automatically open with the application running.

## ✅ How to Run Tests

To ensure all core components are working as expected, you can run the test suite using `pytest`.

From the project root directory, simply run:

```bash
pytest
```
